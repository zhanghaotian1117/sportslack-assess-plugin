# 2026-06-29 Worker 修复说明

本次修复聚焦 v4 在线考试系统接入后的路由和权限细节。

## 修复内容

- 修正 `/v4/assess/` 挂载路径下的静态资源读取逻辑，Worker 会先去掉 `/v4/assess` 前缀再从 `frontend/dist` 读取文件。
- 对前端路由场景增加 `index.html` 回退，避免刷新子页面时直接返回 404。
- 细化 `/v4/assess/api/*` 权限映射：
  - 考生读取试卷、批量读取题目、提交成绩、申请考试/补考、错题相关接口使用 `take` 能力。
  - 阅卷和评分接口使用 `grade` 能力。
  - 题库、标签、分类、用户、导入导出等管理接口继续使用 `manage` 能力。

## 验证

```bash
node --check src/worker.js
```
